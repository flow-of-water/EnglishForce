#1.2 Chúng ta đang upload video qua API, nếu video quá lớn thì sao ? 
API tải nổi không? Hay với cloudinary thì khác? 
Trả lời: ChatGPT:
TH1:  frontend → backend server (Node.js) → Cloudinary
Nếu video quá lớn (ví dụ 500MB, 1GB), thì:
- Tốn RAM server backend vì Express và multer sẽ giữ file đó trong memory hoặc ổ đĩa tạm thời.
- Timeout có thể xảy ra nếu server bạn config timeout thấp.
- Tốc độ upload bị giới hạn bởi băng thông Internet của server backend. Nếu backend không mạnh (ví dụ xài VPS nhỏ), sẽ choke ngay.
- Nếu Node backend server chết (Out of Memory - OOM) thì request lỗi luôn.
TH2: Cloudinary thực ra có cách upload trực tiếp từ client lên Cloudinary (không qua server bạn).
Max file upload size (tùy gói dịch vụ):
- Unsigned upload (miễn phí): khoảng 100MB (có thể config lên 120MB)
- Signed upload (trả phí): hỗ trợ file tới vài GB (thường ~5GB nếu đăng ký cao cấp).
Trong trường hợp cụ thể của chúng ta:
Client → Backend Node.js (qua multer) → Cloudinary
- multer xử lý file từ FormData.
- File được lưu trực tiếp lên Cloudinary nhờ cấu hình CloudinaryStorage.
- Server không giữ file tạm trong ổ đĩa hoặc RAM, vì multer-storage-cloudinary stream file thẳng lên Cloudinary.
Có vẻ vẫn oke nếu số lượng admin (người có thể upload tài nguyên) có số lượng khoảng 30

#9.3.1 Phân cấp và Paging trong ExamStart 
Để có cấu trúc giống TOEIC: 
- Lớp ExamPart đầu tiên (Parent Parts): Listening , Reading 
- Lớp ExamPart thứ 2 (Children Parts): Part 1,2,3,4,5,6,7
- Lớp ExamPart thứ 3 (Grandchildren Parts): Là QuestionGroup, lưu các hỉnh ảnh, đoạn văn đc dùng chung cho 3,4 câu hỏi
Câu hỏi: Các câu hỏi đơn không cần QuestionGroup thì nên tạo ntn ? 
C1: Tạo 1 Part chỉ chứa 1 câu hỏi đó (Với cách này, chúng ta cần thêm orderIndex cho ExamPart)
C2: Tạo trực tiếp câu hỏi từ Lớp ExamPart thứ 2 (Khá khó thực hiện, không biết nên sắp xếp như thế nào với các Lớp ExamPart thứ 3)
Kết luận: 
- QuestionGroup sinh ra chỉ vì 1 số nhóm câu hỏi cần dùng chung Ảnh, Đoạn văn (Part 3,4,6,7)
- 3 Part còn lại 1,2,5 chỉ chứa các câu đơn , có thể dùng C1 
- ExamMenu nên chỉ hiện các phân cấp: Listening, Reading, Part 1,2,3,... Còn cấp QuestionGroup thì không nên hiện dễ loạn 


#9.4 Exam Admin Structure :
- Exam Lists: Add Exam Button, Delete Exam Button
- Exam Detail: Edit Exam Button, Exam Infor , Exam Part Lists, Add Part Button, Delete Part Button
- Exam Part Detail : 
 + Exam Part Infor, Edit Part Button
 + Children Exam Part Lists, Add Child Part Button, Delete Child Part Button, Detail Child Part Button(still redirect to Exam Part Detail)
 + Edit Questions Button 
- Questions list: All questions of one part
- Question Detail: Edit question button, Answer List, Add Answer, Delete Answer Button , Edit Answer Button
